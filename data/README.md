# Data

| Folder | Contents | In git? |
| --- | --- | --- |
| `raw/` | `athlete_events.csv`, `noc_regions.csv` from Kaggle's *120 years of Olympic history* (R. Griffin) | No - downloaded automatically on first run |
| `processed/` | `country_year_features.csv` - one row per Country x Summer Games with every engineered feature | Yes (regenerated by the pipeline) |
| `external/` | `tokyo2020_medals.csv` - real Tokyo 2020 medal table, used **only** to score the 2020 forecast after the fact | Yes |
| `external/` | `world_bank_indicators.csv` - six World Bank WDI series (GDP, GDP per capita, GDP growth, population, population growth, land area) for 217 countries, 1960-2025 | Yes (about 1 MB) |

The raw files are fetched from the dataset author's GitHub mirror
(`github.com/rgriff23/Olympic_history`), which is identical to the Kaggle release.
To download them manually:

```bash
python -c "import sys; sys.path.insert(0, 'src'); from olympic_momentum.data import download_raw_data; download_raw_data()"
```

Cleaning rules (see `src/olympic_momentum/data.py`):

* Summer Games only; the unofficial 1906 Intercalated Games are dropped.
* Team medals are counted **once per event**, matching official medal tables.
* NOC codes are mapped to countries with `noc_regions.csv`, so historical teams
  merge into one history (FRG/GDR -> Germany, URS/EUN -> Russia, HKG -> China).

## World Bank indicators

`world_bank_indicators.csv` is extracted from the World Development Indicators bulk
download (`WDICSV.csv`, about 200 MB, and `WDICountry.csv`), which is too large for git:

```bash
python scripts/prepare_world_bank.py --wdi WDICSV.csv --countries WDICountry.csv
```

Only real countries are kept (aggregates like "World" are dropped), and World Bank
names are mapped to the Olympic country names (see `NAME_TO_ISO3` in
`src/olympic_momentum/economic.py`). For Games held in year *t* the model uses the
value for year *t - 1*. The World Bank has no data for the Soviet Union, East
Germany or Taiwan, so those rows stay missing. Random Forests handle missing values
natively, and the linear models impute inside their own pipelines.
