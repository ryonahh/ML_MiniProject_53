Forecasting the medal table from each country’s momentum

We predict how many Olympic medals a country will win using only earlier Games. The model doesn’t guess the medal count directly. It learns how much a country rises or falls from one Games to the next.

How the pipeline works

Each step uses only information that existed before the Games being predicted. Unit tests check this. For example, changing a future result must never change any past feature.

  1. Clean the records

    271,116 athlete rows from Kaggle’s 120 years of Olympic history. Summer Games only, with team medals counted once per event, as in the official tables.

  2. One row per country per Games

    Athletes, sports, events and medals for 206 countries. Historical teams are merged, so West and East Germany count as Germany and the USSR as Russia.

  3. Look back, never forward

    Nine lagged features: last Games’ medals and golds, team size, sports, events, medal and athlete growth, a three-Games rolling average, and medals per athlete.

  4. Add the World Bank

    The reference paper’s indicators: GDP, GDP per capita, GDP growth, population, population growth, land area, and shares of world GDP and population. Each comes from the year before the Games.

  5. Learn momentum

    A Random Forest predicts the change in log medals since the last Games. The forecast is that change added back to last Games’ count.

  6. Test on the future

    Tuned on London 2012, tested on Rio 2016, backtested on six Games, then used to forecast Tokyo 2020 and scored against the real medal table.

Why predict the change, not the count

A Random Forest can only predict values it has already seen, averaged inside its leaves. If it learns medal counts, one leaf has to cover nations with 3 medals and nations with 90, so the big nations get pulled toward the middle.

Learning momentum fixes this. A country that sent a bigger team and won more medals per athlete last time tends to grow by a similar percentage, whatever its size. The same leaf can then serve Kenya and China.

How the eight models compare

Every model uses the same Random Forest (), averaged over random seeds. Lower error is better.

The paper’s models, re-run on our splits

The reference paper compares many model types. We re-ran each one with history and World Bank features, once predicting the count and once predicting momentum. Each was tuned on 2012 and tested once on Rio 2016. Momentum lowers the error for five of the six types that can use it, including the paper’s own best pairing of Naive Bayes and Ridge. Poisson regression needs a count target, so it has no momentum version.

The real future: Tokyo 2020

The dataset stops at 2016, so these forecasts were made without any 2020 information and then scored against the actual medal table. Tokyo was postponed a year by COVID and hosted by Japan. Here the models with World Bank data do best: the paper’s two-stage design has the lowest error, and the economic models are clearly better on the top ten nations. Predicting momentum, our winner on every earlier Games, falls back to the middle of the pack.

What didn’t work, and what’s left

  • A momentum score as an extra feature

    We first combined medal growth, athlete growth and efficiency into one standardised score. Adding it to a forest that already has those three inputs made no difference (MAE vs ). The idea only helped once momentum became the target.

  • The paper’s two-stage model

    The reference paper first predicts medal or no medal, then how many. Rebuilt with its World Bank inputs, it beats the plain count model and wins on Tokyo 2020, but it trails predicting momentum in every backtest Games.

  • SVR predicting the count

    In the model-family comparison, an RBF-kernel SVR predicting the count has the best RMSE and top-ten error on Rio 2016. Momentum did not help SVR. This is a single test year, so we report it but don’t read too much into it.

  • World Bank data has gaps

    The World Bank has no figures for the Soviet Union, East Germany or Taiwan, so of country-Games rows have no economic data. On Rio 2016 the indicators barely change the error, because last Games’ medals already reflect a country’s wealth and size. They do help on Tokyo 2020 and on the top ten nations.

  • Shocks the data can’t see

    Host-nation effects (Japan won 58 medals in Tokyo, up from 41), boycotts and a COVID-delayed Games are outside what any of these features describe.

  • Feature importance is not cause

    Last Games’ medals and medals per athlete dominate the importance ranking. That shows what the model relies on, not why countries win.
